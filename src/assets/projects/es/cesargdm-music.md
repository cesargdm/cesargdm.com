# cesargdm Music

[cesargdm Music](https://music.cesargdm.com) es un reproductor web para Apple Music construido con React. Usa la [API de Apple Music](https://developer.apple.com/documentation/applemusicapi) para traer la biblioteca del usuario y reproducir canciones.
